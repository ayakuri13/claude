# 恋愛系 note マネタイズ ── 1日15分プレイブック

元ネタの戦略（X記事を量産 → バズらせる → noteリンクで低単価販売）を、
**「他に仕事があって1日15分しか取れない人」向けに現実的な手順へ落とし込んだもの。**

このリポジトリのツール（Grokでバズをリサーチ→記事ドラフト生成）を使う前提で書いている。

---

## 0. 先に正直なところ（過度な期待をしないために）

元noteは「初月0→10万」「1年で1000万」と言うが、それは **数を相当打てる人** の話。
1日15分なら、現実的なゴールはこう置くのが健全：

| 期間 | 現実的な目標 | 何が起きていればOK |
|---|---|---|
| 1ヶ月目 | note公開 + X記事を20本投稿 | 1万imp超えの記事が1〜2本出る |
| 2〜3ヶ月目 | 初売上 〜 月1〜5万円 | 10万imp級が出始め、noteがポツポツ売れる |
| 6ヶ月目 | 月5〜20万円 + 購入者リスト100人 | 「型」が固まり、勝ち記事を再生産できる |

**勝ち筋は「毎日15分を止めないこと」だけ。** 才能より継続。1日サボるより、雑でも1本出す。

---

## 1. 最初の30分だけ：土台を作る（初日のみ）

15分運用に入る前に、一度だけ準備する。

1. **ジャンルを1つに絞る**（複数やらない）
   - 鉄板＝**復縁 / 回避（冷却・追わせる）**。痛みが深く、リピート購入も起きやすい。
   - 次点＝不倫/婚外恋愛、マチアプ攻略、婚活攻略。
   - 選ぶ基準：**自分が語れる実体験 or 強い持論があるか。** ゼロ知識のジャンルは続かない。
2. **アカウントを整える**（プロフィール1行＋固定ポスト枠だけ）
   - 例：「元彼から連絡が来る"引く"恋愛｜復縁で大事なのは追わないこと」
3. **noteを1本だけ作る**（→ `note商品-設計図.md`）。100〜980円でOK。完璧主義は捨てる。
4. **ツール設定**：`config.romance.example.json` の自分のジャンル行を `config.json` にコピー。

これで準備完了。明日から15分ルーティンに入る。

---

## 2. 毎日の15分ルーティン（これが本体）

> 朝でも夜でもいい。**同じ時間に固定**するのがコツ。

| 時間 | やること | 使うもの |
|---|---|---|
| 0〜3分 | 今のバズをリサーチ＋記事ドラフト生成 | `npm run article -- --niche 復縁 --note "<noteのURL>"` |
| 3〜8分 | 出てきたドラフト3本から **1本を選んで手直し**（自分の言葉・実体験を1行足す） | 生成された `data/articles/*.md` |
| 8〜10分 | X記事として投稿 | X |
| 10〜13分 | **セルフ引用を1〜2本**投稿（ドラフトに入ってる引用案を使う） | X |
| 13〜15分 | 同ジャンルの他人の記事を**2〜3件引用RP**（共感コメント付き） | X |

ポイント：
- **書く時間をゼロに近づける。** AIが初稿を出す。あなたは「自分の体温を1行足して投げる」だけ。
- **セルフ引用は必須。** 元記事が伸びなくても、引用の方が伸びることが普通にある。
- **他人を引用する文化を作る。** 自分が引用する人は、自分を引用し返してくれる確率が上がる。これが無名アカウントの生命線。

`article` コマンドが重い日は、`npm run ideation` でネタだけ拾って手書きしてもいい。

---

## 3. 週1回の15分：振り返り（日曜など）

PDCAがすべて。週1で必ず見る：

1. 今週の投稿で **imp上位3本** はどれ？ → なぜ伸びた？（切り口/フック/タイミング）
2. 沈んだ記事との違いは？ → タイトルか、共感の弱さか、ターゲットのズレか。
3. 来週は **勝ったパターンを3本** 再生産する（同じ型・別の切り口）。
4. noteが1件でも売れたら、その記事の導線を他の記事にもコピーする。

「30本書いて3本が10万imp」なら、その3本を分析して量産に回す。これだけで伸びる。

## 4. ツールの使い方（このリポジトリ）

事前に `.env` に `XAI_API_KEY` を設定（→ README）。

```bash
# ① 毎日：今のバズをリサーチ → そのまま投稿できる記事ドラフト3本＋セルフ引用案を生成
npm run article -- --niche 復縁 --note "https://note.com/xxx/n/abc123"

# 別ジャンル・本数・期間を変える
npm run article -- --niche 不倫 --count 3 --hours 72
npm run article -- --niche マチアプ攻略 --dry-run   # プロンプトだけ確認

# ② ネタだけ欲しい日（手書き派）
npm run ideation -- --topic "復縁 男性心理"

# ③ note本体を書く前の地ならし（裏取り・用語・反論）
npm run research -- --topic "復縁で連絡を絶つ期間の考え方"

# ④ 自分や競合のジャンルのバズを毎朝LINEに流す（ネタの自動供給）
#    config.json に恋愛キーワードを入れてから
npm start
```

生成物は `data/articles/` `data/ideation/` に Markdown で残る（git管理外）。

## 5. やってはいけないこと（健全に長く稼ぐために）

- **効果を断定しない。**「絶対よりを戻せる」等はNG（景表法・規約・炎上リスク）。"考え方/テクニック"として書く。
- **個人の特定・晒し・中傷をしない。** あるあるは抽象化して書く。
- **違法・有害（盗撮、ストーカー助長、同意なき行為）は扱わない。**
- **過度に露骨な性的表現はしない**（Xの規約・凍結リスク）。示唆の範囲で。
- **AI丸投げの誤情報に注意。** 自分の実体験・持論を必ず1行は混ぜる（それが差別化＝ファン化の核）。
