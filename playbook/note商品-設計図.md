# note商品 設計図（最初の1本）

「X記事 → noteリンク → 低単価で売る」の"売る側"。
**まず1本を今週中に公開する**のが目的。完璧主義は捨てる。後から差し替えできる。

---

## 1. 価格戦略

| フェーズ | 価格 | 狙い |
|---|---|---|
| 最初の1本 | **100〜980円** | 「初見で買われる」ことを最優先。データと購入者リストを取る |
| 慣れてきたら | 1,500〜3,000円 | X記事で十分に教育できていれば3,000円でもバズ1本で数十個売れる |
| 後から | 高単価ローンチ | 購入者リストが数百人貯まったら別商品を案内 |

> 元ネタの「3,000円×50個＝15万/投稿」は教育が効いた後の話。**最初は安く出して回数をこなす。**

## 2. 7,000字くらいの構成テンプレ（復縁の例）

X記事と同じ「教育→ちょい答え→マインド」を、noteでは"答えを全部出す"。

```
# タイトル（フック）
  例)「追わずに復縁する技術 ── 連絡を絶つ21日と、再接触の入り方」

## はじめに（300字）
  - 誰のための記事か（追ってしまって空回りしている人）
  - 読み終わると何がわかるか（連絡設計の全体像）
  - 軽い自己紹介・なぜ語れるか（実体験/支援実績）

## 第1章：なぜ追うと逆効果なのか（マインド・1500字）
  - 原理（希少性/返報性）。X記事で触れた"気づき"をここで深掘り

## 第2章：連絡を絶つ期間の設計（手順・2000字）★ここが本体
  - 何日・何をしない・SNSはどうする 等を具体的に

## 第3章：再接触の入り方（手順・2000字）
  - 最初の1通のテンプレ、避ける言葉、相手の反応別の分岐

## 第4章：やりがちな失敗と対処（800字）

## おわりに＋次の一歩（400字）
  - 「もっと個別に」→ LINE登録 or 上位商品への導線（任意）
```

7,000字が重ければ **3,000字でもいい**。1本目は「出すこと」が勝ち。

---

## 3. 無料パート / 有料パートの切り方

- **無料（冒頭〜第1章の途中まで）**：共感＋"気づき1個"で「続き読みたい」を作る。X記事と同じ要領。
- **有料（核心の手順から）**：第2章以降。ここに具体的なテンプレ・日数・台詞を置く。

X記事で来た人が「無料パートだけで満足」しないよう、**核心の一歩手前で課金ラインを引く。**

---

## 4. 作り方（15分×数日で1本）

AIで初稿、自分で体温入れ。`npm run research` で裏取りすると質が上がる。

```bash
# 章ごとの裏取り・反論・用語を固める
npm run research -- --topic "復縁 連絡を絶つ期間 男性心理"
```

1. 上の構成をAIに渡して章ごとに初稿生成
2. 各章に**自分の実体験・具体例を1つずつ**差し込む（差別化の核）
3. 無料/有料ラインを引いて公開
4. noteのURLを `npm run article --note "<URL>"` に渡し、X記事から誘導開始

---

## 5. 横展開（2本目以降）

1本売れたら、ジャンル内で**痛みをずらして**増やす：

- 復縁 → 「ブロックされた状態からの復縁」「結婚前提の彼との復縁」
- マチアプ → 「初回デートで落とす」「2回目に繋げるLINE」
- 不倫/婚外 → 「本命になる立ち回り」「バレない以前の関係設計」

X記事は商品ごとに導線を分け、**伸びた記事 = 売れる商品**の組み合わせを残していく。

## 6. リスト取り（任意だが推奨）

- noteの最後とXの固定で **LINE公式へ誘導**（「個別質問OK」等の特典）。
- 購入者が増えたら、そこへ上位商品を案内 → 高単価が決まりやすい。
- 1日15分運用では後回しでOK。**まずはnote1本＋X記事の習慣化が先。**
