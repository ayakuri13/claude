# X記事テンプレート集（恋愛系）

`npm run article` が出すドラフトの「型」の元ネタ。手書きする日や、生成結果を直すときの参照用。
すべて **教育7割・答え1割・マインド2割** が基本構造。核心は出し惜しみ、続きはnoteへ。

---

## A. X記事（長文ポスト）の骨格

```
【フック：刺激的 or 自分ごと化する1〜2行】
  例)「"追う側"でいる限り、彼の気持ちは戻らない。」

【共感 / あるある：読者に"自分のことだ"と思わせる】
  例) 既読スルーされるたびに追いLINE。会いたいと言うほど距離が開く。
      ……これ、9割の人がやってる。

【ちょっとだけ答え：気づきを1個だけ渡す（核心は渡さない）】
  例) 復縁で最初にやるのは「連絡」じゃなくて「連絡しない設計」。
      理由は単純で、人は失って初めて価値に気づくから。

【マインド / なぜ効くか：原理を語って納得させる】
  例) 相手の頭の中であなたが"いつでも手に入る人"になった瞬間、
      恋愛感情は止まる。だから戻すべきは連絡頻度じゃなく、立ち位置。

【CTA：続きはnoteへ】
  例) 具体的な「連絡を絶つ期間と再接触の入り方」は下にまとめた↓
      [NOTE_LINK]
```

スマホで読まれる前提で **改行を多く、1〜2文ごとに空行**。

---

## B. フック（タイトル）の型 × 恋愛

| 型 | テンプレ | 例 |
|---|---|---|
| ターゲティング | 「〜な人にだけ言う」 | 元彼を追ってしまう人にだけ言う |
| 逆説・否定 | 「〜してはいけない」 | 復縁したいなら、好きと言ってはいけない |
| 数字・手順 | 「〇個 / 〇日」 | 復縁率が上がる"沈黙の21日" |
| あるある共感 | 「〜しがち」 | 冷められる女ほど、優しくしすぎる |
| 秘匿性 | 「他では言わない / 本当は教えたくない」 | 復縁屋が絶対に言わない本音 |
| 失敗談 | 「〜で失敗した」 | 追いLINEで完全に嫌われた話 |

→ 1記事につきフックを3パターン作り、一番強いので投稿。残りはセルフ引用に回す。

---

## C. セルフ引用（自分の記事を引用RPして伸ばす）

元記事より引用の方が伸びることが多い。**1記事に3本まで**、型を変えて打つ。

```
■ ターゲティング型
  「元彼にLINE我慢できない人、これまじで読んでほしい。」

■ 秘匿性型
  「これ他の復縁発信ではほぼ見ない視点だと思う。目から鱗だった。」

■ 続き気になる型
  「この記事の"3つ目"が一番効く。多くの人が逆をやってる。」

■ 結論ずらし型
  「復縁の答え、"連絡しない"なんだけど、理由がエグい。」
```

数日に分けて投稿してOK。1本の記事を引用で何度も擦る。

---

## D. 短文ポスト（バズ構文）の型

記事だけでなく、軽いポストも数を打つ。最後のリプにnoteリンク。

```
〇〇な人の特徴

・△△
・△△
・△△

当てはまったら、たぶん□□。
```

```
復縁でやりがちな失敗 TOP3

3位 すぐ会おうとする
2位 重い長文LINE
1位 ○○○○○

（リプに続き）
```

10回投げて1〜2回跳ねれば勝ち。**伸びなくて当たり前、数で確率を取りに行く。**

## E. リサーチ管理（スプレッドシート）

伸びてる外れ値ポストを50件ストックして、AIに型を学ばせる土台にする。

| 列 | 内容 |
|---|---|
| URL | 投稿リンク |
| imp | インプレッション |
| いいね/RP | エンゲージ |
| フォロワー数 | ※100〜1万規模の外れ値を重視（10万超は参考外） |
| 切り口 | 復縁/回避/不倫… |
| フック | 1行目だけ写経 |
| メモ | なぜ伸びたかの仮説 |

`npm start`（バズ検知のLINE通知）や `npm run ideation` の出力をここに貯めると楽。

---

## F. 注意（テンプレ運用の地雷）

- 効果の断定（「絶対戻る」）を入れない。"考え方"の語尾にする。
- 実在人物の特定・晒しをしない。あるあるは抽象化。
- 露骨な性描写は避ける（凍結リスク）。
- **自分の実体験・持論を最低1行混ぜる** → これがAI量産との差＝ファン化の核。
