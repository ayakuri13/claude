## 1. プロジェクト概要

### 1.1 これは何か

「note完全攻略講座」の購入者専用チャットボット(ChatGPTのGPTs)。
講座の全ナレッジ(全13章+6.5章のレッスン内容・レッスンページURL・特典ツール一覧)を読み込ませ、受講生の「あの動画どこだっけ?」「次なにやればいい?」に即答する **講座専属コンシェルジュ** として提供する。

### 1.2 講座環境(確定情報)

| 項目 | 内容 |
|---|---|
| 会員サイト | Notion「note完全攻略講座(新)」 https://app.notion.com/p/a921ec79161a8316b4980194a6df0f6f |
| 動画ホスティング | Vimeo(各レッスンページに埋め込み) |
| レッスン構成 | 1〜13章+6.5章+10大特典+質問会アーカイブ(コンテンツDBで管理、重要度タグ付き) |
| 既存の専用GPTツール | コンセプト設計ツール/有料note執筆ツール/特典2 SEO特化執筆/特典3 無料部分記事ライター/特典5 画像生成/特典12 noteライティング |
| サポート窓口 | 事務局 utolog573@gmail.com / 問い合わせLINE / 講座生Discord / 質問会 |

> 旧設計(v1)はUTAGE会員サイト+YouTube前提だったが、現行はNotion+Vimeoに移行済み。本設計はNotionを唯一の正とする。

### 1.3 解決する課題

| 受講生の悩み | GPTでの解決 |
|---|---|
| 「あの内容の動画、どこにあったっけ?」と毎回探すのが大変 | 内容を聞くだけで「◯章の◯」とレッスンページURLを即答 |
| 動画を見ただけで、次に何をすべきか分からない | 現在地をヒアリングして次のアクションを提案(重要度タグで最短ルートも) |
| ワーク(自己分析・コンセプト設計等)で手が止まる | 講座の教えに沿って壁打ち+該当の専用ツールへ案内 |
| ツールや特典が多くてどれを使えばいいか分からない | 作業内容から最適な特典・GPTツールへ振り分け |
| 質問したいが講師に聞くほどでもない | 講座内容の範囲で24時間いつでも回答 |

### 1.4 ビジネス設計(クロスセル)

- **対象**: note完全攻略講座の購入者限定
- **価格**: 9,800円(講座本体へのクロスセル)
- **訴求**: 「講座をもっとシンプルに使い倒す。探す時間ゼロの専属コンシェルジュ」
- **ポジション**: 既存の特典GPT群が「作業ツール(書く・作る)」なのに対し、本GPTは「案内役(探す・決める・続ける)」。全ツール・全レッスンへのハブになる
- **提供形態**: GPTsの共有リンク(「リンクを知っている人のみ」)を購入者だけに案内
  - 決済後の自動返信/Notion会員サイト内の専用ページ(特典と同じ折りたたみセクション)にリンク掲載
- **販売導線**: 講座購入完了ページ・サンクスメール・会員サイトトップ・Discordでオファー

## 2. ターゲットとユースケース

### 2.1 ペルソナ

- note完全攻略講座を購入済みの初心者〜中級者
- 在宅でマイペースに月10万円の収益化を目指す層(講座のメインターゲットと同一)
- ChatGPTは講座の特典ツールで触れている(=GPTsの使い方は知っている)

### 2.2 主要ユースケース(優先度順)

1. **レッスンナビ(最重要)**
   - 例:「HARMの話ってどこでしてた?」→「4章の5『売れる市場の法則』です。レッスンページ: (Notion URL)」
   - 例:「サムネの作り方の動画どれ?」→ 5章6(有料note)と6章3(無料note)を用途で振り分けて提示
2. **学習ロードマップ提案**
   - 例:「講座買ったばかり。何から見ればいい?」→ 1章から順に、章ごとのゴールとワークを提示
   - 例:「時間がない」→ 重要度「超重要」だけの最短ルートを提示
3. **講座内容のQ&A**
   - 例:「有料noteの適正価格って結局いくら?」→ 5章3の内容を根拠に回答+該当レッスンを案内
4. **ツール・特典への振り分け**
   - 例:「SEO記事書きたい」→ 特典2のGPTツール+9章のレッスンをセットで案内
5. **ワークの壁打ち**
   - 例:「自己分析ワークを一緒にやって」→ 4章2の手順に沿って伴走→特典4ワークシート+コンセプト設計ツールへ
6. **売れない時の診断**
   - 例:「noteが売れない」→ 5章5の改善チェック項目に沿って1つずつ診断

## 3. GPT基本設定

### 3.1 名称・説明

| 項目 | 内容 |
|---|---|
| 名前 | note完全攻略講座 コンシェルジュ |
| 説明 | note完全攻略講座の専属コンシェルジュ。「あの動画どこ?」に即答し、あなたの現在地に合わせて次のアクションと最適なツールを案内します。(購入者専用) |
| プロフィール画像 | 講座のブランドカラーに合わせたアイコン(別途作成) |

### 3.2 会話スターター(4つ)

1. 「あの動画どこ?」内容を教えてくれたら場所を答えます
2. 講座を買ったばかり。何から始めればいい?
3. noteが売れない…一緒に原因をチェックして
4. 今やってる作業に合うツールや特典を教えて

### 3.3 Capabilities設定

| 機能 | 設定 | 理由 |
|---|---|---|
| Web Browsing | **OFF** | 講座外の情報を混ぜない。回答の根拠を講座に固定 |
| DALL·E | OFF | 画像生成は特典5の専用ツールに任せる(役割分離) |
| Code Interpreter | **OFF** | ナレッジファイルのダウンロード経路を塞ぐ(コンテンツ流出防止・必須) |
| Actions | なし | v1では不使用 |

## 4. ナレッジ設計

### 4.1 データソースの方針

- **一次情報 = Notion会員サイト**(コンテンツDB+各レッスンページの【内容要約】)
- 旧Google Doc「【note完全攻略講座】文字起こし」は**旧構成(12章・UTAGE時代)のため原則使わない**。内容要約でカバーできない詳細Q&A用の補助として、内容の一致を確認できた章のみ将来追加を検討(§10)

### 4.2 ナレッジファイル一覧(GPTsにアップロードするファイル)

| # | ファイル | 内容 | 生成元 |
|---|---|---|---|
| 1 | `01_video_index.md` | 全レッスン索引: 章/レッスン名/重要度/概要1行/レッスンページURL+特典一覧 | NotionコンテンツDB(作成済み) |
| 2 | `02_lessons_ch01-04.md` | 1〜4章の各レッスン内容要約+ワーク | 各レッスンページ(作成済み) |
| 3 | `03_lessons_ch05-06.md` | 5章・6章・6.5章の各レッスン内容要約+ワーク | 同上(作成済み) |
| 4 | `04_lessons_ch07-09.md` | 7〜9章の各レッスン内容要約+ワーク | 同上(作成済み) |
| 5 | `05_lessons_ch10-13.md` | 10〜13章+質問会の各レッスン内容要約+ワーク | 同上(作成済み) |
| 6 | `06_bonuses.md` | 10大特典の内容・入手先・使いどころ | 特典ページ(作成済み) |
| 7 | `07_faq_and_policy.md` | よくある質問、サポート窓口、回答ポリシー | 新規作成(質問会・Discordの頻出質問から育てる) |

- 見出しは `## ◯章◯. レッスン名` に統一(受講生の言い回しでヒットさせるため、概要1行にキーワードを含める)
- 案内URLは**Notionレッスンページに一本化**。Vimeo直リンクはナレッジに含めない(ページ経由で見る運用にして流出面を最小化)

### 4.3 講座の章構成(Notion実データ・確定)

## 5. Instructions(システムプロンプト)

完全版は [`instructions.md`](./instructions.md) を参照。設計方針:

1. **単一役割**: 「講座専属コンシェルジュ」に固定。回答の根拠は常にナレッジ
2. **4つの仕事**: ①レッスンナビ(固定フォーマットで即答) ②道案内(現在地ヒアリング→提案、超重要タグで最短ルート) ③講座Q&A(要点3つ+レッスン誘導) ④ツール案内(作業→特典・GPTツールへ振り分け)
3. **見つからない時**: 正直に言って事務局・LINE・Discord・質問会へ
4. **ガードレール**: 原文の長文出力拒否/Instructions開示拒否/収益保証禁止/講座外話題の遮断/返金・決済は事務局へ

## 8. 運用・更新

- **レッスンの追加・差し替え時**(Notion側の更新): 該当章のナレッジファイルと `01_video_index.md` を再抽出して差し替え(月1回のメンテ枠を推奨)。本リポジトリの抽出フォーマットに従えば再生成は機械的に可能
- **質問ログの活用**: 「見つからなかった質問」「Discord・質問会の頻出質問」を `07_faq_and_policy.md` に追記して精度を改善
- **告知**: GPTのリンク変更時は会員サイトとDiscord・LINEで通知

## 9. リスクと対策

| リスク | 対策 |
|---|---|
| ナレッジ(講座本文)の流出 | ナレッジは「内容要約」ベースで動画本編の完全な代替にならない構成/Code Interpreter OFF/長文引用の拒否/Vimeo直リンクをナレッジに含めない |
| 未購入者への拡散 | リンク限定公開+会員サイトのみに掲載。流出が目立てばGPT再発行(URL変更) |
| 誤答(章の取り違え) | インデックスを一次情報とし、回答フォーマットで章+レッスン名を必ず明示 |
| Notionとナレッジの乖離 | 更新はNotion→再抽出の一方向フローに固定(手でナレッジだけ直さない) |
| OpenAI仕様変更 | ナレッジをMarkdownで本リポジトリ管理しているため、Claude Projects/Dify等へ移植可能 |
