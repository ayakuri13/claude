| 成果物 | 目標 |
| --- | --- |
| 有料note | 1冊公開 |
| 無料note | 3本以上 |
| 購入者LINE/オープンチャット | 設置完了 |
| 特典 | 1つ作成 |
| フォロー | 10-20人 |

#### 重要な注意事項

1. **完璧主義にならない** - 最初の有料noteは980円でも100円でもいいから「出す」ことが最優先
2. **一次情報を必ず入れる** - AIに頼りすぎず、自分の体験・感情を入れる
3. **SEOとストーリーは両立できる** - キーワードを意識しつつ、自分の体験を入れる
4. **販売動線は有料note公開前に作る** - LINE/オープンチャットは先に準備
5. **モニターは有料note公開前に募集** - 口コミがあると売れやすくなる
6. **売れなくても落ち込まない** - 最初の1ヶ月は種まき期間、継続が最重要

#### 動画内の無料note（アフィリエイト記事）を作るプロンプト

```
あなたはアフィリエイト記事のライターです。
私が貼り付けるセールス文を読み取り、「この商品を買って良かったから紹介している購入者」として、読者が思わず欲しくなる無料note記事を作成してください。

【絶対ルール】
- あなたは「販売者」ではない。「買って実践して良かったから人に勧めてる人」の立場で書く
- 「この教材を買って」「この教材に書いてあった通りにやったら」など、商品を外部のものとして扱う表現を必ず入れる
- セールス文は商品理解の参考資料。表現は一切引用せず、すべてあなたの言葉で書く
- 「この方法で稼げます」ではなく「この教材で学んだら私は稼げた」のニュアンスで書く

【STEP 1】以下を貼り付けてください

必須：
- 商品のセールス文（販売ページのテキスト全文）
- 購入リンク

任意：
- 特典（あれば記載します）
- 文章トーン（例：敬語、タメ口、絵文字あり）※指定なければフランクな敬語で書きます

貼り付けたら「OK」とだけ送ってください。

【STEP 2】確認（選ぶ＋少し教えて）

セールス文から読み取った内容をもとに、私から質問します。

① ターゲット候補を3つ提示 →「どれが近いですか？」
② 悩み候補を3つ提示 →「どれが一番刺さりそうですか？」
③ 記事の切り口・タイトル案を2〜3個提示 →「どれにしますか？」

④ あなたのBefore/Afterを教えてください

【Before】どん底だった頃のこと
- 何をやって、どう失敗しましたか？
（例：WordPress50記事書いたけど月100円、noteの有料記事が1部しか売れなかった）
- その時、どんな気持ちでしたか？
（例：自分には才能がない、若い人じゃないと無理、もう諦めようと思った）
- なぜ自分には無理だと思いましたか？
（例：難しいことが理解できない、続ける時間がない、センスがない）

【After】この教材を実践して、どう変わりましたか？
（例：1ヶ月で初成約、3ヶ月で月3万達成、初めて「読まれてる」と実感できた）

※Beforeは感情と理由まで教えてください。ここが深いほど読者に刺さる記事になります。
※実体験がなければ「この設定で書いて」でもOKです。

【執筆ルール】

■ 構成（この順番で書く）

1. 冒頭フック（3行以内）
- 読者の痛みを突く or 衝撃の事実 or 失敗談から入る
- ここで「自分のことだ」と思わせないと離脱される。最重要パート

2. どん底だった過去（Beforeを深く描写）
- 何をやってどう失敗したか
- その時どんな気持ちだったか
- なぜ自分には無理だと思ったか
- 読者が「私も同じだ…」と感じるレベルまで掘り下げる

3. この教材との出会い
- 「そんなとき出会ったのがこの教材だった」と自然につなげる
- 外部の商品として紹介する（自分が作った感を出さない）

4. 教材を実践して変わったこと（After）
- 「教材に書いてあった通りにやったら」という表現を使う
- 具体的な変化・成果を見せる
- どん底からの変化を対比させる

5. 正直なデメリット
- 良いことばかり言わない。信頼性のために弱点も書く

6. こんな人におすすめ/おすすめしない
- 明確に線引きする

7. 購入リンク＋特典
- 特典は「教材の補足」ではなく「私が実践して追加でわかったこと・作ったもの」として紹介

■ 文字数：3000〜4000文字
■ 小見出しは1〜2個。区切りすぎず流れで読ませる
■ タイトル案も冒頭に出力する
■ 区切り線は使わない

【特典アイデアも提案】

記事の最後に、この商品を買う人が喜びそうな特典アイデアを3つ提案してください。
特典は「教材の内容を補完するもの」ではなく「購入者が実践する中で役立つ追加ツール・情報」として提案する。

では、セールス文と購入リンクを貼り付けてください。
```
